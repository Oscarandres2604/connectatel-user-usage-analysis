# Analisis para empresa de telecomunicaciones 'ConnectaTel' – Data analyst bootcamp, sprint 7

Este proyecto analiza los patrones de uso de los servicios móviles de ConnectaTel para identificar oportunidades de mejora en la oferta comercial y la experiencia del cliente. A partir de los datasets `plans.csv`, `users_latam.csv` y `usage.csv`, se realizó un proceso de exploración, limpieza y validación de datos, incluyendo el tratamiento de valores nulos, sentinels e inconsistencias en las fechas.

Se integraron las fuentes de datos para analizar el consumo de llamadas y mensajes, identificar valores atípicos y segmentar clientes según sus características demográficas, comportamiento de uso y plan contratado.

El análisis se desarrolló en Python utilizando Pandas, NumPy, Matplotlib y Seaborn para generar visualizaciones, identificar patrones relevantes y formular recomendaciones orientadas a la toma de decisiones basada en datos.

## 📂 Contenido del repositorio

- `Project-tripleten-analysis-ConnectaTel.ipynb`
  → En el notebook se trabajo identificando valores invalidos y sentinels, limpieza general de datos, correccion de sentinels y fechas imposibles, union de datasets relevantes, resumen estadistico general, visualizacion de distribuciones y outliers, segmentacion de clientes y recomendaciones finales.

## 🧠 Proposito del analisis

- Analizar patrones de uso: Examinar el consumo de llamadas y mensajes de los clientes de ConnectaTel.

- Garantizar la calidad de los datos: Identificar y tratar valores nulos, sentinels, inconsistencias y fechas inválidas.

- Detectar comportamientos atípicos: Identificar valores extremos que puedan requerir revisión adicional.

- Segmentar clientes: Comparar patrones de consumo según la edad, volumen de consumo y el plan de suscripción.

- Apoyar decisiones comerciales: Generar insights y recomendaciones para optimizar los planes y mejorar la experiencia del cliente.
